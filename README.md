# NeuralSpeechIA

[![Project Video](https://img.shields.io/badge/Watch%20the-Video-FF0000?style=for-the-badge&logo=youtube)](https://www.youtube.com/watch?v=B5_9zbCxxHk)

Keyword spotting running **entirely on an Arduino Due**: press a button, say "bonjour" (hello) or "merci" (thank you) in French, and the OLED screen shows the recognized word along with its confidence score.

The whole pipeline is written by hand, with no embedded ML framework: register-level audio acquisition, digital filtering, on-device MFCC extraction, and inference of a small convolutional neural network written in plain C.

*Student project, 2025.*

## How it works

```
Mic ──► ADC 32 kHz ──► FIR filter + ×4 decimation ──► 8 kHz ──► MFCC ──► CNN ──► OLED
       (TC0 timer)     (53 taps, Q15)                          (48×13)   (plain C)
```

| Stage | Details |
|---|---|
| Acquisition | TC0 timer and ADC configured directly through registers (SAM3X8E), sampling at ~32 kHz on A0 |
| Filtering | 53-tap low-pass FIR filter in Q15 fixed-point, followed by ×4 decimation → 8 kHz |
| Framing | 256-sample frames with an 89-sample overlap |
| Features | 26 Mel filters → 13 MFCC coefficients per frame, 48 frames (≈ 1 s of audio) |
| Normalization | Per-coefficient z-score, identical in Python and C |
| Model | Conv2D(8) → MaxPool → Conv2D(16) → MaxPool → Dense(8) → Dense(2), ≈ 5,900 parameters (~23 KB) |
| Inference | Convolution, max-pooling, dense layers and softmax reimplemented in C |

## Hardware

- Arduino Due
- Amplified analog microphone, output on **A0**
- Push button between pin **52** and GND (internal pull-up enabled)
- SSD1306 128×64 I2C OLED display (address `0x3C`)

## Repository layout

```
arduino/
├── audio_capture/      Captures raw filtered audio and streams it over serial (debug)
├── mfcc_export/        Computes MFCCs on the board and sends them to the PC (dataset creation)
└── voice_classifier/   Final program: MFCC + CNN + OLED display
    └── model_weights.h Network weights, generated by train_cnn.py

python/
├── mfcc_receiver.py    Records the MFCCs sent by the board into a dataset file
├── train_cnn.py        Trains the CNN and exports the weights as a C header
├── audio_receiver.py   Records the raw audio sent by audio_capture (debug)
└── affichage_mfcc/     Plots the captured signal (debug)

dataset/
└── dataset_perso/      50 "bonjour", 50 "merci" and 10 test samples
```

## Usage

### Dependencies

- **Arduino**: Adafruit SSD1306 and Adafruit GFX libraries, plus the `arduinoMFCC` library (not included in this repository).
- **Python**: `pip install numpy tensorflow pyserial matplotlib`

### 1. Build the dataset

Upload `arduino/mfcc_export` to the board, then from the `python/` folder:

```bash
python mfcc_receiver.py bonjour --n 50 --port COM5
python mfcc_receiver.py merci --n 50 --port COM5
```

For each recording: press the button, say the word, then press `Enter` to keep it, `r` to redo it or `q` to quit. Move the resulting files into `dataset/dataset_perso/`. The `datatest.txt` file contains 5 "bonjour" samples followed by 5 "merci" samples.

### 2. Train the model

```bash
cd python
python train_cnn.py
```

The script generates `model_weights.h`, which must be copied into `arduino/voice_classifier/`.

### 3. Run the recognition

Upload `arduino/voice_classifier` to the board, press the button and say "bonjour" or "merci". The screen displays "Hello" or "Thank you" with the confidence score.

## Limitations

- The model only knows two words: any other sound will be classified as one of them.
- The dataset was recorded by a single speaker, so recognition is less reliable with other voices.
